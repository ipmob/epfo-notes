# EPFO Notes

Study notes for the UPSC EPFO syllabus item "Industrial Relations, Labour Codes and Social Security in India".

- Notes are built from statute text, not from coaching material.
- Practice questions are derived from previous-year questions (PYQs) and adapted to the current syllabus.
- The site is static and is published with GitHub Pages from the `docs/` folder.

See `ROADMAP.md` for the plan and `CLAUDE.md` for the working rules.
