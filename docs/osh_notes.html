Thirteen Acts on factories, mines, plantations, contract labour, migrant workers, construction, docks and other workplaces became one Code on occupational safety, health and working conditions. This topic teaches the Code first: who is covered, registration, hours and leave, welfare and safety, contract labour, migrant workers and penalties. The old Acts appear only to show what changed.

Law today The Occupational Safety, Health and Working Conditions Code, 2020 OSH Code (Act 37 of 2020) is in force in full from 21 November 2025 (S.O. 5321(E)). It repealed 13 Acts OSH Code s.143(1). The Central Government may fix different dates for different provisions OSH Code s.1(2), but the notification fixes one date for the whole Code. The Occupational Safety, Health and Working Conditions (Central) Rules, 2026 (G.S.R. 345(E), 8 May 2026) are in force from the date they were published in the Gazette OSH Central Rules r.1(3). A point marked with a Rules chip comes from the Rules, not the Code text.
  1. 13 Acts, 1 Code. The Code has 143 sections and 14 chapters. It was assented to on 28 September 2020 and is in force in full from 21 November 2025.
  2. Who is covered. An establishment with 10 or more workers OSH Code s.2(1)(v). A factory with 20 or more workers with power, 40 or more without OSH Code s.2(1)(w). Contract labour: 50 or more OSH Code s.45(1)(i). Inter-State migrant workers: 10 or more OSH Code s.59. Mines and docks have no worker threshold.
  3. Hours and leave. 8 hours a day OSH Code s.25(1)(a). The 48-hour week is in the Rules OSH Central Rules r.64(1), not in the Code. Overtime at 2 times wages, with the worker's consent OSH Code s.27. Leave with wages after 180 days worked, 1 day for every 20 days OSH Code s.32(1).
  4. Welfare and safety. Canteen at 100 or more workers OSH Code s.24(1)(v). Crèche at more than 50 workers OSH Code s.24(3). Welfare officer at 250 or more OSH Code s.24(2)(iv). Ambulance room at more than 500 OSH Code s.24(2)(i). Safety Committee at 500 or more in the Rules OSH Central Rules r.14(1); the Code gives no number OSH Code s.22(1).
  5. Contract labour and penalties. Contract labour in core activities is barred, with 3 exceptions OSH Code s.57(1). A death caused by a contravention: imprisonment up to 2 years, or a fine of not less than Rs 5 lakh, or both OSH Code s.103(1)(a). Compounding: 50% of the maximum penalty, 75% of the maximum fine OSH Code s.114(1).

2. Definitions and who is covered

For the wages definitions shared by all the Codes, see Topic 7, Code on Wages. The OSH Code's own wording is below.

OSH Code s.2(1)(v) Establishment

A place where an industry, trade, business, manufacturing or occupation is carried on and 10 or more workers are employed.

A motor transport undertaking, newspaper establishment, audio-video production, building or other construction work, or plantation, also needs 10 or more workers.

A mine, or a port or its vicinity where dock work is carried out, has no worker threshold.

The 10-worker threshold does not apply to an establishment where a hazardous or life threatening activity, notified by the Central Government, is carried on.

OSH Code s.2(1)(w) Factory

Premises with 20 or more workers (now, or on any day of the preceding 12 months) where a manufacturing process is carried on with power. With 40 or more workers where it is carried on without power.

If a State law fixed a different number before the Code, that number prevails in the State until the State Legislature amends it.

old Factories Act 1948 s.2(m) 10 or more workers with power, 20 or more without Changed
OSH Code s.2(1)(zx) Plantation

Land used for growing tea, coffee, rubber, cinchona or cardamom that measures 5 hectares or more. Other plants can be added by State notification.

OSH Code s.2(1)(zs) Occupier

The person with ultimate control over the affairs of the factory. For a company, any one of the directors other than an independent director. For a firm, one of the partners.

OSH Code s.2(1)(zzl) Worker

Anyone employed in an establishment for manual, unskilled, skilled, technical, operational, clerical or supervisory work for hire or reward.

Excluded: a supervisor drawing wage above Rs 18,000 a month (or a notified amount), armed forces, police and prison staff, and managerial or administrative staff. The definition has no out-worker exclusion.

old CLRA 1970 the definition of "workman" excluded an out-worker Removed
OSH Code s.2(1)(t) Employee

A person (other than an apprentice under the Apprentices Act 1961) employed on wages for skilled, semi-skilled, unskilled, manual, operational, supervisory, managerial, administrative, technical, clerical or other work. It excludes members of the Armed Forces of the Union.

"Employee" is wider than "worker" because it takes in managerial and administrative staff.

OSH Code s.2(1)(ze) Inspector-cum-Facilitator

The officer appointed under OSH Code s.34(1). The appropriate Government may appoint Inspector-cum-Facilitators by notification.

The factory test is not the same in the two Acts. The old Act said 10 with power and 20 without. The Code says 20 with power and 40 without. The contract labour test also moved, from 20 to 50.

3. Registration, licence and returns

OSH Code ss.3(1), 3(3) Registration

An employer of an establishment that comes into existence after the Code starts, and to which the Code applies, applies electronically to the registering officer within 60 days of applicability. The certificate of registration is issued electronically.

OSH Code s.3(8) Existing registrations

An establishment already registered under a Central labour law is deemed registered under the Code if the holder gives the details to the registering officer in the prescribed time and form.

OSH Code s.119(1) Common licence

One may apply for a common licence for a factory, industrial premises for beedi and cigar work and engaging contract workers, or any combination of them, or a single licence for any one of them. The common licence is optional.

OSH Code ss.47, 48(3) Contractor licence

A contractor who wants a licence for more than one State or the whole of India may obtain it from the authority designated by the Central Government. The licence is valid for 5 years for the number of contract labour named in it.

OSH Code s.6(1)(f) Appointment letter

The employer issues a letter of appointment to every employee on appointment. An employee who has none when the Code starts gets one within 3 months of commencement.

Rules. No employee is employed unless an appointment letter in the prescribed format is issued OSH Central Rules r.6. The format has items for type of employment, wages (basic pay and dearness allowance), applicability of social security (EPFO and ESIC) and the broad nature of duties.

OSH Code s.37 Third party audit

The appropriate Government may notify a scheme to empanel experts for third party audit and certification for start-up establishments or classes it specifies. Experts are assigned in a randomised manner through a web-based scheme.

OSH Code s.33(d) Return

The employer files a return, electronically or otherwise, with the Inspector-cum-Facilitator, in the manner and during the periods the appropriate Government prescribes.

Rules. Every employer sends an annual return in FORM-XVII to the Inspector-cum-Facilitator, electronically, to reach on or before the last day of February after each calendar year OSH Central Rules r.74. A return in FORM-XVII and XVIII is uploaded on or before the 28th or 29th day of February OSH Central Rules r.73(5).

The Code does not use the words "single" or "annual" for the return. OSH Code s.33(d) leaves the manner and periods to the Government. The annual return comes from the Rules OSH Central Rules r.74.

4. Hours, overtime and leave

OSH Code s.25(1) Daily hours

No worker is required or allowed to work in an establishment for more than 8 hours in a day OSH Code s.25(1)(a). Intervals and spread-over are left to notification by the appropriate Government OSH Code s.25(1)(b).

Factories Act 1948: 9 hours a day old Factories Act 1948 s.54. Spread-over 10.5 hours old Factories Act 1948 s.56, which the Chief Inspector may raise to 12 hours Changed
OSH Code s.26(1) Six-day week

No worker is allowed to work for more than 6 days in any one week.

OSH Central Rules r.64(1) Weekly hours (Rules)

No worker is required or allowed to work for more than 48 hours in a week. The Code text has no weekly hour figure.

old Factories Act 1948 s.51 48 hours for an adult worker. The number is the same. The source is now the Rules, not the Code Changed

Many books say the Code gives "8 hours a day, 48 hours a week". The Code fixes 8 hours a day only OSH Code s.25(1)(a). The 48-hour week is in the Rules OSH Central Rules r.64(1).

OSH Code s.27 Overtime

Wages at twice the rate of wages for overtime work. The overtime period is calculated on a daily or weekly basis, whichever is more favourable to the worker.

Overtime work is subject to the consent of the worker. The appropriate Government may prescribe the total hours of overtime.

Rules. A worker other than a daily wager who works more than 48 hours in a week is paid twice the rate of wages OSH Central Rules r.69(1)(b). No worker is allowed to work overtime exceeding 144 hours in any quarter of a year OSH Central Rules r.69.

old Factories Act 1948 s.59 twice the rate Same
OSH Code s.32(1) Leave with wages

Eligibility. A worker who has worked 180 days or more in a calendar year OSH Code s.32(1)(i).

Counted days. Layoff, maternity leave and annual leave availed in the year count toward the 180 days. The worker does not earn leave for the days so counted OSH Code s.32(1)(iii).

Carry-forward. At most 30 days are carried forward to a succeeding year OSH Code s.32(1)(vii)(a). Leave refused after the worker applied can be carried forward without limit.

Encashment. On the worker's demand, leave is encashed at the end of the calendar year OSH Code s.32(1)(viii). Clause (ix) lets the worker encash leave above 30 days.

old Factories Act 1948 s.79 240 days or more to qualify. Layoff days counted and earned no leave, as now Changed
WorkerLeave earned
Any other worker OSH Code s.32(1)(ii)1 day for every 20 days of work
Adolescent worker1 day for every 15 days

Worked example: layoff and leave

A worker works 220 days in a year and is laid off for 25 days. The layoff days count toward the 180 days, so 220 + 25 = 245 and the worker qualifies. Leave is earned only on the 220 days worked: 220 / 20 = 11 days.

5. Women, health check-up and age

OSH Code s.43 Women and night work

Women are entitled to be employed in all establishments for all types of work under the Code. They may also be employed, with their consent, before 6 a.m. and beyond 7 p.m., subject to prescribed conditions on safety, holidays and working hours.

Rules. Night or early-late work needs the woman's written consent, adequate transport, a well-lit workplace with closed-circuit television on the way to toilets, washrooms and drinking facilities, and compliance with the Sexual Harassment of Women at Workplace Act 2013 OSH Central Rules r.83.

Factories Act 1948: women not employed between 7 p.m. and 6 a.m., relaxable between 10 p.m. and 5 a.m. A factory-only bar became a consent rule for all establishments Changed
OSH Code s.44 Dangerous operations

Where the appropriate Government considers employment of women dangerous to their health and safety, it may require the employer to provide adequate safeguards first.

Rules. The Central Government may declare by notification the class of establishments and the standard for safeguarding women in hazardous processes OSH Central Rules r.84.

OSH Code s.6(1)(c) Annual health check-up

The employer provides an annual health examination or test, free of cost, to the employees of the age or class the appropriate Government prescribes.

Rules. Every employer of dock work, building or other construction work arranges a free medical examination for an employee who has completed 40 years of age OSH Central Rules r.5(1). The rule covers only those two kinds of work.

OSH Code ss.2(1)(b), 2(1)(a) Adult and adolescent

An adult is a person who has completed 18 years of age. An adolescent has the meaning in CAL Act 1986 s.2(i). The Code itself states no age range.

Factories Act 1948: an adolescent is a person who has completed 15 years but not 18 Changed
OSH Code s.42(2)(c) Fitness certificate

The medical officer appointed under OSH Code s.42(1) examines and certifies adolescents for fitness for employment in a factory, plantation, motor transport undertaking or other prescribed establishment. The Code uses "medical officer", not "certifying surgeon".

Factories Act 1948: the certifying surgeon gave the certificate Changed

Proof of age OSH Code s.117(2)

  1. Aadhaar card The medical authority prescribed by the Central Government takes the Aadhaar card first.
  2. School certificate Then the school date-of-birth or matriculation certificate.
  3. Birth certificate Then a birth certificate from a corporation, municipal authority or Panchayat.
  4. Ossification test Only if none of these exists.

7. Contract labour (Chapter XI, Part I)

OSH Code s.45(1)(i) Where Part I applies

Every establishment with 50 or more contract labour, now or on any day of the preceding 12 months. Part I also covers every manpower supply contractor with 50 or more contract labour.

old CLRA 1970 20 workmen Changed
OSH Code s.45(2) Intermittent work

The Part does not apply to an establishment where work only of an intermittent or casual nature is performed. Work is not intermittent if done for more than 120 days in the preceding 12 months, or, if seasonal, for more than 60 days in a year.

OSH Code s.2(1)(p) Core activity

Any activity for which the establishment is set up, including any activity essential or necessary to it.

These are not treated as essential or necessary if the establishment is not set up for them: sanitation works, watch and ward including security, canteen and catering, loading and unloading, support-service hospitals and guest houses, courier services, civil and constructional works, gardening, housekeeping and laundry, transport including ambulance services, and any activity of intermittent nature.

Is the work a core activity of the establishment? OSH Code s.57(1)

Yes Contract labour is prohibited. Three exceptions: the activity is ordinarily done through a contractor given the normal functioning of the establishment; it does not need full-time workers for the major part of the working hours or for longer periods; or there is a sudden increase in the volume of work that must be done in a specified time.
No The ban does not apply. Sanitation, security, canteen and the other activities named in OSH Code s.2(1)(p) fall here when the establishment is not set up for them.

Sanitation, canteen and security are not exceptions to the ban. They are part of the definition of "core activity", so they are outside it from the start. The three exceptions in OSH Code s.57(1) are separate tests.

OSH Code ss.53, 55 Welfare and wages

Welfare. The principal employer provides the welfare facilities under OSH Code s.23 and OSH Code s.24 to the contract labour employed in the establishment OSH Code s.53. This duty is direct, not "if the contractor fails".

Wages. The contractor pays wages to each contract labour OSH Code s.55. If the contractor fails to pay in the prescribed period, or short pays, the principal employer pays the wages in full or the unpaid balance. The principal employer recovers it from the contractor by deduction or as a debt OSH Code s.55(3).

In SAIL v National Union Water Front Workers (2001), (2001) 7 SCC 1, the Supreme Court held that contract workers are not automatically absorbed by the principal employer on abolition of contract labour.

The licence and common licence rules are under "Registration, licence and returns" above.

8. Inter-State migrant workers (Chapter XI, Part II)

OSH Code s.2(1)(zf) Who is a migrant worker

A person employed in an establishment who draws wages not exceeding Rs 18,000 a month, or a higher amount the Central Government notifies.

It also covers a person who came on his own from one State and got work in an establishment of another State, or later changed establishment within that State, if there is an agreement or other arrangement for the employment.

OSH Code s.59 Where Part II applies

Every establishment with 10 or more inter-State migrant workers, now or on any day of the preceding 12 months.

OSH Code s.60 Facilities

The contractor or employer ensures suitable conditions of work. A fatal accident or serious bodily injury is reported to the authorities of both States and to the next of kin. The worker gets every benefit a worker of the establishment gets, including ESI Act 1948 and EPF Act 1952 benefits and the medical check-up under OSH Code s.6(1)(c).

OSH Code s.61 Journey allowance

The employer pays every inter-State migrant worker, in a year, a lump sum equal to the fare for a to-and-fro journey to his native place.

Rules. A lump sum for travel not less than II Class sleeper or bus, once in twelve months, if the worker worked not less than 180 days in the establishment in the preceding twelve months OSH Central Rules r.102.

OSH Code ss.62, 63 Ration, cess and helpline

The appropriate Government makes schemes so that a migrant worker can use public distribution system benefits in his native State or the destination State. It also makes schemes for portability of building and other construction cess fund benefits in the destination State, for a worker in building or other construction work OSH Code s.62.

The appropriate Government may provide a toll free helpline OSH Code s.63. Rules: the Director General Labour Welfare Organisation shall provide a toll-free help-line number OSH Central Rules r.103.

OSH Code s.21(2) Database

The Central and State Governments keep a database or record of inter-State migrant workers on a portal. A worker may register himself on self-declaration and Aadhaar.

Rules. The employer furnishes details and statistics of inter-State migrant workers OSH Central Rules r.13.

OSH Code ss.59 to 65 No displacement allowance

The Code has no displacement allowance. The migrant worker provisions in OSH Code ss.59 to 65 pay none.

old ISMW Act 1979 displacement allowance of 50% of monthly wages or Rs 75, whichever is higher Removed. The contractor also had duties of equal pay for the same or similar work, suitable residential accommodation, protective clothing, prescribed medical facilities and a journey allowance. The Act had no old-age benefit.

Contract labour starts at 50 workers OSH Code s.45(1)(i). Inter-State migrant workers start at 10 OSH Code s.59. The migrant wage limit is Rs 18,000 a month OSH Code s.2(1)(zf). Do not swap the numbers.

9. Mines and plantations (bridge)

Mines

OSH Code s.41 Entry to a mine

A Government servant authorised by the Chief Inspector-cum-Facilitator or an Inspector-cum-Facilitator may enter a mine to survey, level or measure it or its output after giving not less than 3 days' notice to the manager. In an emergency, no notice is needed.

old Mines Act 1952 a special officer gave the manager at least 3 days' notice Same
OSH Code s.25(1) Mine hours

Below-ground hours are left to Central Government notification OSH Code s.25(1). The Code has no mine size threshold OSH Code s.2(1)(v).

old Mines Act 1952 48 hours a week, 9 a day above ground and 8 a day below ground. The Act applied to all mines regardless of size Changed
OSH Code s.43 Women below ground

The Code allows women in all types of work. Rules: in a below-ground mine, not fewer than three women on duty at any place OSH Central Rules r.83(g).

old Mines Act 1952 barred women below ground. A relaxation by notification allowed it, with written consent and safeguards Changed

A mine with 100 or more workers needs a safety officer OSH Code s.22(2). Mine employees are medically examined before employment and at intervals OSH Code s.24(1)(vi).

The State Government may prescribe that every plantation employer provides necessary housing accommodation, including drinking water, kitchen and toilet, for every worker and family. It is a Code facility only as the State rules prescribe.

The State Government may prescribe crèches where 50 or more workers are employed (or were employed on any day of the preceding 12 months), including workers of a contractor. It may prescribe educational facilities where children aged 6 to 12 exceed 25, health facilities for worker and family or ESI coverage, and recreational facilities.

10. Penalties and compounding

OSH Code s.94 General penalty

A penalty of not less than Rs 2 lakh and up to Rs 3 lakh on the employer or principal employer. A further penalty up to Rs 2,000 for each day the contravention continues after conviction. It is a penalty, not imprisonment.

old Factories Act 1948 s.92 imprisonment up to 2 years or a fine up to Rs 1 lakh Changed
OSH Code s.103(1)(a) Death through a contravention

Where non-compliance with duties causes an accident or dangerous occurrence resulting in death: imprisonment up to 2 years, or a fine of not less than Rs 5 lakh, or both.

The court may direct that a portion of the fine, not less than 50%, be given as compensation to the victim, or to the legal heirs if the victim died OSH Code s.103(1).

Rs 5 lakh is a minimum, not a maximum. The law says the fine "shall not be less than" Rs 5 lakh OSH Code s.103(1)(a).

OSH Code s.114(1) Compounding

A listed penalty may be compounded for 50% of the maximum penalty. A listed offence may be compounded for 75% of the maximum fine.

No compounding for a second or later penalty or offence within 3 years of one earlier compounded or convicted. The compounding sum goes to the social security fund for unorganised workers OSH Code s.115.

Answers

  1. 21 November 2025, by S.O. 5321(E). It repealed 13 Acts OSH Code s.143(1).
  2. 20 or more workers with power, 40 or more without OSH Code s.2(1)(w). The old Act said 10 and 20.
  3. In the Rules OSH Central Rules r.64(1). The Code fixes only 8 hours a day OSH Code s.25(1)(a).
  4. Yes. The 25 layoff days count, so 220 + 25 = 245, which is above 180. Leave is earned on the 220 days worked: 220 / 20 = 11 days OSH Code s.32(1).
  5. The Code gives no number OSH Code s.22(1). The Rules say 500 or more OSH Central Rules r.14(1). A safety officer at 250 is needed in a hazardous-process factory and in a building or other construction work OSH Code s.22(2).
  6. A canteen at 100 or more workers OSH Code s.24(1)(v). A crèche at more than 50 workers OSH Code s.24(3). The crèche says "more than".
  7. Contract labour in core activities is barred OSH Code s.57(1). Exceptions: the activity is ordinarily done through a contractor; it does not need full-time workers for the major part of the working hours or for longer periods; or there is a sudden increase in the volume of work.
  8. Imprisonment up to 2 years, or a fine of not less than Rs 5 lakh, or both OSH Code s.103(1)(a). No: Rs 5 lakh is a minimum.
  9. 50% of the maximum penalty, and 75% of the maximum fine for an offence OSH Code s.114(1).
