Four Acts on wages, payment of wages, bonus and equal pay became one Code. This topic teaches the Code first: who is covered, how minimum and floor wages work, when wages are paid, what can be deducted, how bonus is worked out, and how claims, inspection and penalties run. The old Acts appear only to show what changed.

Law today The Code on Wages, 2019 Wages Code (Act 29 of 2019) is in force from 21 November 2025 (S.O. 5322(E)). The Central Advisory Board parts came earlier, on 18 December 2020 (S.O. 4604(E)). It repealed four Acts: the Payment of Wages Act 1936, the Minimum Wages Act 1948, the Payment of Bonus Act 1965 and the Equal Remuneration Act 1976 Wages Code s.69(1). The Code on Wages (Central) Rules 2026 (G.S.R. 343(E)) are in force from 8 May 2026. A point marked with a Rules chip comes from the Rules, not the Code text.
  1. 4 Acts, 1 Code. The Code has 69 sections and 9 chapters. It was assented to on 8 August 2019 and came into force in two steps.
  2. Wages Wages Code s.2(y) means basic pay, dearness allowance and retaining allowance. Excluded items above one-half of all remuneration are added back. Pay in kind counts up to 15%.
  3. Minimum wage covers any employee Wages Code s.5. The Code has no schedule of employments. Rates are reviewed ordinarily at intervals not above 5 years Wages Code s.8(4). The Central Government fixes the floor wage Wages Code s.9.
  4. Payment: wage period at most 1 month Wages Code s.16; monthly wages before the 7th day of the next month Wages Code s.17(1)(iv); deductions at most 50% Wages Code s.18(3); fines at most 3% Wages Code s.19(4); overtime at least 2 times the normal rate Wages Code s.14.
  5. Bonus: at least 30 days worked; minimum 8.33% or Rs 100; maximum 20%; paid within 8 months Wages Code ss.26, 39(1). Claims go to an authority within 3 years Wages Code s.45(6). Compounding costs 50% of the maximum fine Wages Code s.56.

Wages

Wages Code s.2(y) Wages

All remuneration in terms of money. It includes basic pay, dearness allowance and retaining allowance, if any.

The one-half rule. If payments under clauses (a) to (i) of the exclusion list exceed one-half of all remuneration, or another percentage the Central Government notifies, the excess is added back to wages. Gratuity and retrenchment compensation are outside clauses (a) to (i), so they do not count in this test.

In kind. Remuneration in kind, given in place of part or all of the wages, counts as wages up to 15% of the total wages payable.

The IR Code s.2(zq), the Code on SS s.2(88) and the OSH Code s.2(zzj) carry the same items and the same one-half proviso.

The Minimum Wages Act counted house rent allowance as wages. The Code excludes it, subject to the add-back Wages Code s.2(y)(f) Changed

Worked example: the one-half rule

Basic Rs 20,000 plus DA Rs 5,000 is Rs 25,000. Excluded items are Rs 35,000. All remuneration is Rs 60,000, so half is Rs 30,000. The excess of excluded items over half is Rs 5,000, and it is added to wages.

All remuneration: Rs 60,000 (half is Rs 30,000)
Basic + DA: Rs 25,000
Excluded items: Rs 35,000
Excess added back: Rs 5,000
Wages for the Code: Rs 25,000 + Rs 5,000 = Rs 30,000

4. Minimum wage and floor wage (Chapter II)

Wages Code s.6(6) How the rate is fixed

The appropriate Government shall primarily take into account the skill of workers (unskilled, skilled, semi-skilled, highly-skilled), or geographical area, or both Wages Code s.6(6)(a). It may, in addition, take into account arduousness: temperature or humidity normally difficult to bear, hazardous occupations or processes, underground work Wages Code s.6(6)(b).

The norms of fixation are "such as may be prescribed" Wages Code s.6(6)(c) needs rules. The Code states no calorie, cloth or housing norm.

Wages Code ss.6(2), 6(3), 12 Time work and piece work

A minimum rate may be fixed for time work or for piece work Wages Code s.6(2). For piece workers, the rate must secure a minimum wage on a time-work basis Wages Code s.6(3). Where only a minimum time rate is fixed for piece work, the employer pays at least that time rate Wages Code s.12.

Wages Code s.7(1)(a) Basic rate plus cost-of-living allowance

A minimum rate may be a basic rate plus a cost of living allowance, adjusted at intervals the appropriate Government directs, to follow the cost of living index number. The Code sets no frequency.

The Rules fix one: the cost of living allowance and the cash value of concessions on essential commodities are computed once before 1 April and once before 1 October every year, to revise the variable dearness allowance. The base is the Average Consumer Price Index for Industrial Workers published by the Labour Bureau Wages Central Rules r.4.

From proposal to review, and the floor wage

  1. Fix the rate Wages Code s.8(1) The appropriate Government either appoints committees to hold enquiries and recommend, or publishes its proposals by notification and names a date not less than 2 months later.
  2. Floor wage first Wages Code s.9(1) The Central Government fixes the floor wage, taking into account the minimum living standards of a worker. Different floor wages may be fixed for different geographical areas.
  3. No rate below it Wages Code s.9(2) Minimum rates fixed by the appropriate Government shall not be less than the floor wage, and an earlier higher rate is not reduced.
  4. Review Wages Code s.8(4) Review or revise "ordinarily at an interval not exceeding five years". The floor wage has the same limit Wages Central Rules r.10(4).

The Central Government may obtain the advice of the Central Advisory Board and consult State Governments before fixing the floor wage Wages Code s.9(3). The Rules name "food, clothing, housing and any other factors" for the floor wage and leave the criteria to a Central Government order Wages Central Rules r.3(1), 10(1). They do not repeat consumption norms.

"May" and "shall" are different in this chapter. Skill or geographical area is a shall Wages Code s.6(6)(a). Arduousness is a may Wages Code s.6(6)(b). The Board's advice on the floor wage is also a may Wages Code s.9(3).

5. Payment of wages (Chapter III)

Chapter III does not apply to Government establishments unless the appropriate Government notifies it Wages Code s.25.

Wages Code ss.15, 16 Mode and wage period

Mode. Wages are paid in current coin or currency notes, or by cheque, or by crediting the bank account of the employee, or by the electronic mode. The proviso lets the appropriate Government notify establishments that must pay only by cheque or bank credit. The proviso names cheque and bank credit, not the electronic mode Wages Code s.15.

Wage period. Daily, weekly, fortnightly or monthly. No wage period for any employee is more than a month Wages Code s.16.

When wages fall due Wages Code s.17

Wage basisDue
Daily Wages Code s.17(1)(i)At the end of the shift
Weekly Wages Code s.17(1)(ii)On the last working day of the week, that is, before the weekly holiday
Fortnightly Wages Code s.17(1)(iii)Before the end of the second day after the end of the fortnight
Monthly Wages Code s.17(1)(iv)Before the expiry of the 7th day of the next month. There is no 10th-day alternative and no head-count test.
On exit Wages Code s.17(2)Within 2 working days of removal, dismissal, retrenchment or resignation, or of becoming unemployed because the establishment closed
Wages Code s.18 Deductions

In any wage period, total deductions are at most 50% of the wages Wages Code s.18(3). The Code has no separate higher limit for dues to a co-operative society. The excess may be recovered in the manner prescribed Wages Code s.18(4) needs rules Wages Central Rules r.13.

Permitted purposes Wages Code s.18(2) include amenities and services supplied by the employer (e), recovery of advances (f)(i), and payment to a co-operative society on the Government's conditions (j).

old PW Act 1936 s.7(3) 50% of wages, or 75% where deductions include payments to a co-operative society Changed
Wages Code s.19 Fines

A fine is at most 3% of the wages payable for that wage period Wages Code s.19(4). No fine on an employee under 15 years Wages Code s.19(5). A fine is not recovered by instalments, and not after 90 days from the day it was imposed Wages Code s.19(6).

Fines and realisations are recorded in a register and applied only to purposes beneficial to the persons employed, as the prescribed authority approves Wages Code s.19(8).

old PW Act 1936 s.8(4) 3% of wages Same
Wages Code ss.13, 14 Overtime, hours and rest

Overtime is paid for every hour or part of an hour worked beyond the normal working day, at not less than twice the normal rate of wages Wages Code s.14.

The Code only lets the Government fix the hours Wages Code s.13(1)(a). The Rules fix them: a daily-wage employee has a normal working day of 8 hours; for other wage periods the total weekly hours are not above 48 Wages Central Rules r.5.

The appropriate Government may provide a day of rest in every period of seven days Wages Code s.13(1)(b). The Rules provide one rest day in every week, ordinarily Sunday Wages Central Rules r.6.

Under Wages Central Rules r.3(2) the daily rate is divided by 8 for the hourly rate and multiplied by 26 for the monthly rate.

6. Payment of bonus (Chapter IV)

Wages Code s.26(1) Eligibility and minimum bonus

Bonus is paid to every employee drawing wages not above an amount per month fixed by notification, who has worked at least 30 days in an accounting year. The Code gives no rupee figure. S.O. 4711(E) of 25 August 2026 fixes Rs 21,000 a month, deemed in force from 21 November 2025.

The minimum bonus is 8.33% of the wages earned, or Rs 100, whichever is higher. It is payable whether or not there is any allocable surplus in the previous accounting year.

old Bonus Act 1965 s.2(13) Rs 21,000, as raised by the Payment of Bonus (Amendment) Act 2015 from the accounting year starting 1 April 2014. old Bonus Act 1965 s.10 8.33% or Rs 100 Changed
Wages Code s.26(2) Calculation base

Where the wages exceed the notified amount, bonus is calculated as if the wage were the notified amount or the minimum wage fixed by the appropriate Government, whichever is higher. The Code names no figure. S.O. 4710(E) of 25 August 2026 notifies Rs 7,000 a month, deemed in force from 21 November 2025.

old Bonus Act 1965 s.12 Rs 7,000 or the minimum wage for the scheduled employment, whichever is higher Changed

Worked example: the calculation base

The minimum wage fixed for an employee is Rs 9,000. That is above Rs 7,000, so the base is Rs 9,000. Rs 9,000 x 12 = Rs 1,08,000. At 8.33%, the bonus is about Rs 8,996.

Notified amount: Rs 7,000
Minimum wage fixed: Rs 9,000, the higher, so this is the base
Wages Code s.26(3) Maximum bonus

Where the allocable surplus exceeds the minimum bonus, bonus is in proportion to the wages earned, up to a maximum of 20% of those wages.

old Bonus Act 1965 s.11 maximum 20% Same
Wages Code s.26(6) New establishments

In the first 5 accounting years after the employer first sells goods or renders services, bonus is payable only for a year in which the employer makes a profit.

Wages Code s.36 Set-on and set-off

Surplus above the 20% maximum (set on) and a shortfall in the minimum bonus (set off) are carried forward up to and including the fourth accounting year.

Wages Code s.39(1) Time of payment

By crediting the employee's bank account within 8 months from the close of the accounting year. The appropriate Government may extend the period for sufficient reasons, and the total extension cannot exceed 2 years.

old Bonus Act 1965 s.19 8 months Same
Wages Code s.29 Disqualification

An employee is disqualified if dismissed for: fraud; riotous or violent behaviour on the premises; theft, misappropriation or sabotage of the establishment's property; or conviction for sexual harassment.

old Bonus Act 1965 s.9 three grounds: fraud; riotous or violent behaviour; theft, misappropriation or sabotage. The Code adds sexual harassment as the fourth Changed

7. Equality, boards, claims, inspection and penalties

Equal remuneration

Wages Code s.3(1) Equal pay

No discrimination in an establishment among employees on the ground of gender in matters relating to wages by the same employer, for the same work or work of a similar nature.

old ER Act 1976 s.4 equal remuneration for the same work or work of a similar nature Same
Wages Code s.3(2) Recruitment and conditions

The employer shall not reduce the wage rate of any employee to comply with Wages Code s.3(1). The employer shall not discriminate on the ground of sex while recruiting for the same or similar work, or in the conditions of employment. The exception: where the law prohibits or restricts the employment of women in such work.

old ER Act 1976 s.5 no sex discrimination in recruitment, with the same exception Same
Wages Code ss.2(v), 4 Same work, and disputes

"Same work or work of a similar nature" means work for which the skill, effort, experience and responsibility required are the same, under similar working conditions. Any differences between employees of any gender are not of practical importance Wages Code s.2(v). A dispute on whether work is of the same or a similar nature is decided by the authority the appropriate Government notifies Wages Code s.4.

The Equal Remuneration Act rested on Constitution Art 39(d).

Claims and appeals

  1. Claim Wages Code s.45(1) The appropriate Government appoints by notification one or more authorities, not below the rank of a Gazetted Officer, to hear and determine claims.
  2. File within 3 years Wages Code s.45(6) From the date the claim arises. The authority may take it later on sufficient cause.
  3. Decision Wages Code s.45(2) In addition to the claim, the authority may award up to 10 times the claim determined as compensation. It and the appellate authority shall endeavour to decide within 3 months Wages Code s.49(3). "Endeavour" is a duty to try, not a fixed limit.
  4. Appeal within 90 days Wages Code s.49 To an appellate authority, which is an officer at least one rank higher Wages Code s.49(2). Later on sufficient cause.

Inspector-cum-Facilitator

Wages Code s.51 Role and inspection scheme

The appropriate Government appoints Inspector-cum-Facilitators. They may advise employers and workers on compliance and inspect the establishments assigned to them Wages Code s.51(5). The old Acts used the word "Inspector".

The appropriate Government may lay down an inspection scheme by notification. It may include a web-based inspection and electronic calling of information, and it may give the officer jurisdiction for randomised selection of inspection Wages Code ss.51(2), 51(3).

Before prosecution, does the employer get a chance to comply? Wages Code s.54(3)

First offence under Wages Code s.54(1)(c) or Wages Code s.54(2) The officer gives a written direction with a time to comply. If the employer complies, no prosecution starts.
Same kind of violation repeated within 5 years No such chance is given. Paying less than due Wages Code s.54(1)(a) never gets the chance.

Compounding Wages Code s.56

On the accused's application, a notified Gazetted Officer may compound an offence for 50% of the maximum fine for that offence. Offences punishable with imprisonment only, or with imprisonment and also with fine, are excluded. No compounding for an offence committed a second time or later within 5 years of a similar offence that was earlier compounded or that led to conviction Wages Code s.56(2).

Maximum fine Rs 50,000 Wages Code s.54(1)(a): compound for Rs 25,000
Maximum fine Rs 20,000 Wages Code s.54(1)(c): compound for Rs 10,000
Maximum fine Rs 10,000 Wages Code s.54(2): compound for Rs 5,000

Three different 50% figures. One is the add-back test in the wages definition Wages Code s.2(y). One is the cap on total deductions Wages Code s.18(3). One is the share of the maximum fine paid to compound Wages Code s.56.

Test yourself

  1. Which four Acts did the Code on Wages repeal, and from what date is the Code in force?
  2. Under the Code, what counts as "wages", and what happens when excluded items pass one-half of all remuneration?
  3. Who is covered by minimum wage under the Code? What happened to the old schedule of employments?
  4. By which day of the next month must monthly wages be paid? Does the number of persons employed change this?
  5. What are the maximum shares for deductions and for fines?
  6. An employee's minimum wage is Rs 9,000 and the notified amount is Rs 7,000. On what wage is bonus worked out?
  7. Within what time must a wage claim be filed, and what is the longest compensation the authority may add?
  8. Name the supervisor wage limit in "worker" under the Wages Code and under the IR and OSH Codes.

Answers

  1. The Payment of Wages Act 1936, the Minimum Wages Act 1948, the Payment of Bonus Act 1965 and the Equal Remuneration Act 1976 Wages Code s.69(1). In force from 21 November 2025, except the Central Advisory Board parts from 18 December 2020.
  2. Basic pay, dearness allowance and retaining allowance, if any Wages Code s.2(y). The excess of clauses (a) to (i) over one-half of all remuneration is added back to wages.
  3. Any employee Wages Code s.5. The Code has no schedule.
  4. Before the expiry of the 7th day Wages Code s.17(1)(iv). No: the old head-count test (7th or 10th day) is gone.
  5. 50% of the wages for deductions Wages Code s.18(3); 3% of the wages for fines Wages Code s.19(4).
  6. Rs 9,000, the higher of the two Wages Code s.26(2). The yearly figure is Rs 1,08,000 and the bonus at 8.33% is about Rs 8,996.
  7. Within 3 years Wages Code s.45(6); compensation up to 10 times the claim Wages Code s.45(2).
  8. Rs 15,000 a month under the Wages Code s.2(z); Rs 18,000 under the IR Code s.2(zr) and the OSH Code s.2(zzl).
